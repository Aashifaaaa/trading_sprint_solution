# Trading Sprint Solution

## Native PostgreSQL workflow

Docker is optional for Sprint 3 + Sprint 4. If the development VM reports that virtualization support is unavailable, use PostgreSQL 16 installed directly in the VM. The Sprint 3 acceptance criteria concern the PostgreSQL schema, migrations, seed loading, constraints, indexes and probes; Docker itself is not an acceptance criterion. Sprint 4 runs Python + DuckDB and also does not require Docker.

See `README_NATIVE_POSTGRES.md` and `START_HERE.md`.
